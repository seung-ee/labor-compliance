# 용어 격차 측정 질의 세트

**목적** — 법제처 기존 검색이 구어체 질의를 얼마나 처리하는지 측정.
임베딩을 만들지 말지를 이 결과로 결정한다.

**측정 방법** — 각 질의를 그대로 넣고 정답 조문이 상위 N건에 들어오는지 확인.
- 경로 A: `lawSearch.do?target=law` (기본 키워드 검색)
- 경로 B: `lawSearch.do?target=aiSearch` (지능형 법령검색)
- 경로 C: 일상용어 → 법령용어 연계 → 조문

**판정**
- 경로 B·C가 잘 나오면 → 임베딩 불필요. 몇 주 절약
- 못 찾으면 → 실패 사례가 곧 `phrase_map` 시드이자 임베딩 평가셋

> ⚠️ 아래 정답 조문은 **잠정**이다. 하네스 실행 시 법제처 API 응답으로 검증할 것.

> **2026-09-20 라벨 수정** — #15·#16을 제20조 → **제43조**로 변경.
> 제20조(위약 예정의 금지)는 *사전에* 위약금·손해배상액을 **예정하는 계약**을 금지하는
> 조문이다. 지각 공제나 파손액 일방 공제는 사후 행위이므로 제43조①(임금은 통화로
> 직접 전액 지급)의 전액불 원칙 위반 쟁점이다. 조문 원문으로 확인했다.
> 사전에 "지각 1회 5천원" 식으로 정해둔 경우라면 제20조가 맞으므로, 질의를 나중에
> 두 갈래로 쪼개는 것을 검토할 것.
